# 网申快填使用指南

[返回项目首页](../README.md) · [下载与安装](../README.md#下载与安装) · [隐私政策](privacy-policy.md)

本页补充首次使用之后的操作细节、旧数据迁移与常见问题。新用户先按首页的「快速开始」安装桌面应用和浏览器扩展。

## 删除招聘通知

在「招聘通知 → 回收站」选择一条通知，点击「永久删除」，核对弹窗中的通知标题和删除范围，再确认。取消不会删除；执行失败时弹窗保留，可以重试或取消。

永久删除会移除这条通知的正文、当前关联和 AI 整理建议；无人引用的原件及其邮件内嵌附件一并清理，共用文件保留。申请、已记录的进度和待办、邮箱中的邮件及已有备份保留。删除后不能在回收站恢复；如需找回，可以从删除前的备份恢复。

若提示通知已删除、原件尚未清理完成，可到「设置 → 数据与备份」检查附件并重试清理。

## 反馈问题与错误报告

插件侧栏「填写」页（一键填写和填写诊断下方）提供“手动反馈问题”，默认折叠，点“展开”填写。填写问题描述，可勾选最近一次填写诊断（做过「保存岗位到桌面端」时还附上岗位流程的固定代码，不含公司和岗位名），点击“预览将发送的内容”，核对不含个人信息、简历或密钥后点击“确认发送”。草稿、发送中或发送失败时都可以点“收起”，收起不会清除草稿，也不会取消正在进行的发送。发送成功后草稿和预览清空并自动收起，只显示反馈编号；下次展开是新的草稿，需要重新预览确认。失败不会自动重试，草稿保留，可展开修改后重新预览发送，两次发送至少间隔 60 秒。浏览器后台休眠后预览可能失效，界面会提示重新预览确认。

“自动错误报告”与“手动反馈问题”互相独立。群里和社交平台上的反馈很多只有一句“填不上”，很难找到原因；开启自动错误报告后，插件出错、字段没填上或 AI 请求失败时，会自动把当时的技术情况发给我们，不含简历和填写内容。它要你同意后才开启：安装或更新插件后，会自动打开「插件状态」页，说明在“插件自动错误报告”框内展开，点“同意并开启”或“暂不开启”；还没选的话，打开侧栏时一键填写按钮下方也会显示同样的说明和选项。选择之前不发送任何自动报告，下次打开还会询问。以后开启或关闭，在「插件状态」页勾选或取消勾选“开启插件自动错误报告”；需要重看说明时，在该框内点“查看完整说明”展开、点“收起说明”收起。关闭会删除随机安装编号，不影响填写和手动反馈。从早期测试版升级，或报告内容增加时，会重新询问一次，明确关闭的选择保留。

桌面端的自动错误报告也要你同意后才开启，第一次打开时会在主窗口上方显示同样的选择；“桌面自动错误报告”和“插件自动错误报告”分开设置，可随时分别在桌面“设置 → 隐私”和「插件状态」更改。该页也有“反馈问题”，自动附上版本和系统，同样先预览再确认发送。

报告在我们这里最多保存 90 天；其中的网站域名和填写统计可能会公开在网申快填的 GitHub 项目里，用于复现问题，公开的内容不随 90 天删除。详情见[隐私政策](privacy-policy.md)。

## 使用数量统计

使用数量统计默认开启，与自动错误报告分开。桌面第一次打开、插件更新后第一次打开侧栏时都会显示一段简短说明；完整字段、保留时间和删除规则在桌面“设置 → 隐私”以及[隐私政策](privacy-policy.md#使用数量统计)中查看。

桌面和插件共用同一个统计开关。可以在桌面“设置 → 隐私”或「插件状态」开启、关闭，另一端会读取同一结果。例如，在插件状态页关闭后，桌面设置也会显示已关闭，桌面和插件都停止发送使用信号；“插件自动错误报告”和“桌面自动错误报告”不会跟着改变。

插件只把空的使用信号和开关操作交给已运行的桌面程序，不直接连接统计服务，也不会为统计启动已退出的桌面。旧桌面不支持共用开关时，插件会提示先启动或更新桌面程序。

## 连接与安装方式

优先从 [Chrome 商店](https://chromewebstore.google.com/detail/diagjmploldedipjdenmecmjokckelkl)安装扩展。商店审核及更新分发可能晚于 GitHub；商店不可用、版本落后于发布页配套插件或提示不兼容时，使用[正式版下载页](https://19991107.xyz/tools/wangshen-kuaitian/download/)中的插件 ZIP，操作见[手动安装](../README.md#手动安装扩展)。

桌面和扩展独立发版，版本号不要求相同。使用发布说明列出的配套版本，不要单靠数字是否一致判断兼容性。

桌面至少打开一次，再重启浏览器，让浏览器读取连接注册。点击工具栏图标打开侧边栏后：

- 显示「这个浏览器还没和桌面配对」：复制扩展 ID，在桌面「设置 → 浏览器连接」中按提示配对。
- 显示「需要先安装桌面程序」：确认桌面已安装、能正常启动，再检查连接注册。
- 显示正常的模板与字段：已经连接。

只有界面提示需要配对时才手动处理扩展 ID。关闭桌面窗口会收起到托盘或菜单栏；主动退出后，插件后台查询和同步不会重新启动桌面，重启浏览器也不会。双击桌面程序或点击插件的「打开桌面」后恢复连接，待同步数据继续保留。

插件状态页可从侧边栏底部的「插件状态」进入，或右键工具栏图标选择「选项」。

## AI 配置

进入桌面「设置 → AI 设置」，添加服务商并设为「当前使用」。

| 设置 | 填什么 |
| --- | --- |
| 接口地址 | 服务商提供的 OpenAI Chat Completions 兼容接口地址 |
| API Key | 该服务商发给你的密钥 |
| 模型 | 点击「获取模型」选择，并确认账号有权限使用 |

可以添加多个服务商，切换当前使用的配置。软件不赠送模型额度，也不代办 API 账号。请尽量使用 HTTPS；HTTP 会明文传输请求。

「强模型（可选）」可以从已保存的服务商里选一个，插件侧栏的「深度分析本页」用它分析页面结构，并用它重新匹配填写（见下文「深度分析本页」）；不选就全部用当前服务商。选作强模型的服务商没有 Key 时，深度分析会直接提示，不会改用当前服务商。删掉被选作强模型的服务商后，这一项自动回到「不使用」。其他用途（一键填写、简历解析、岗位识别、收件箱整理）始终用当前服务商。

预设里有 OpenCode Go。它只能用走 Chat Completions 的模型（OpenCode 文档模型表里 Endpoint 是 chat/completions 的那些），Grok、GPT 等走其他接口的模型用不了。

API Key 保存在 macOS 钥匙串或 Windows 凭据管理器中，不写进扩展，不进入桌面备份。恢复备份后，需要检查并按提示重新配置密钥。

不配置 AI，仍可导入 Excel 模板、点击字段辅助填写，并使用本地岗位管理。AI 简历解析、AI 填写、岗位识别中的 AI 回退和通知 AI 整理需要可用的服务商配置。

## 简历与我的信息

### 用 AI 解析简历

在桌面「简历」页选择 AI 解析，导入 PDF、DOCX 或 TXT。发送前会显示服务商和字数，确认后再发送。

PDF、DOCX 会先在本机提取文字，随后把文字发送给配置的 AI 服务商。扫描件、加密 PDF 等无法提取文字时，请改用可提取文字的 PDF、DOCX 或 TXT。

解析完成会生成新模板并设为当前。AI 可能遗漏或理解错字段，请在模板里核对，也可导出 Excel 修改后再导入。

一个模板最多 24 KB（24,576 字节，按 UTF-8 计，一个汉字约 3 字节）。解析结果超过上限时，可以取消勾选分组或字段、缩短内容后再保存，也可以先把解析结果导出成 Excel，改完再导入。这两种做法都不会再次调用 AI。

### Excel 与 CSV 格式

前三列按顺序为「一级分类」「字段名」「值」，第一行为表头。

| 一级分类 | 字段名 | 值 |
| --- | --- | --- |
| 基本信息 | 姓名 | 张三 |
| 基本信息 | 邮箱 | example@example.com |
| 教育背景 | 学校 | 示例大学 |
| 教育背景 | 专业 | 材料科学与工程 |
| 教育背景 | 学历 | 硕士 |
| 教育背景 | 入学时间 | 2023-09 |
| 教育背景 | 毕业时间 | 2026-06 |
| 实习经历 | 公司 | 示例公司 |
| 实习经历 | 岗位 | 研发实习生 |

保存为 `.xlsx` 或 UTF-8 编码的 `.csv`，在桌面「简历」页导入。Excel 只读取第一个工作表。「字段名」不能留空，学校、专业、学历等信息建议拆开填写。

导入采用整份校验：有一行缺少字段名，整个文件都不会生效，当前模板保持不变。提示会列出错误行号；错误很多时，请检查第二列是否因插入、删除列而错位。

### 多套模板与补充资料

最多可保存 25 套模板，例如研发岗、产品岗、英文简历等。网页填写前在侧边栏切换「当前模板」，选择会同步到桌面。

「我的信息」适合补充籍贯、户口、家庭成员等简历里通常没有的网申字段。

桌面正在编辑时，若扩展新增了补充字段，当前草稿会保留。选择「稍后处理」可以继续编辑；「放弃未保存修改并重新读取」需要再次确认。当前不会自动合并本地草稿和外部修改。

## 自动填写与手动补填

在当前网申表单中点击「一键 AI 填写」，完成后检查提示和高亮字段。再次填写时，若本次匹配的字段已有内容，会在 AI 匹配完成后、写入前询问是否允许重新填写。

取消覆盖确认，本次不写入字段；之前发出的 AI 请求不会撤回。网站提交前仍需自行核对。

手动补填时，先点击网页中没填好的文本输入框，再点击侧边栏字段。空输入框可以直接点击字段填写；已有内容时，字段右侧提供：

| 操作 | 行为 |
| --- | --- |
| 添加 | 在上次点击的光标位置插入该字段，切到侧边栏后仍会记住位置 |
| 替换 | 用该字段替换整个输入框 |
| 删除 | 删除这个字段对应的内容，保留其他内容 |

输入框里已包含的字段会加深显示；不会改变内容的操作会变灰。「简历字段」页支持搜索全部字段。

密码、验证码、文件上传和非文本控件不会启用这些文本操作按钮。普通输入框、文本框、下拉框、单选框以及部分日期和级联控件已有适配，高度定制的页面仍需手动处理。

## 岗位保存与填写留档

### 保存岗位和确认投递

在侧边栏「填写」页点击「保存岗位到桌面端」，核对公司和岗位后确认保存。来源网址只读且已脱敏；需要 AI 识别时会说明发送的页面文字数量，并可取消。疑似重复的岗位由你选择关联已有申请或另存为新申请。

「确认已投递」会查找当前公司在桌面中的申请，让你选择对应岗位，即使只有一条也不会自动替你选。没有候选或无法识别公司时，先保存岗位，再回来选择。

**该操作仅更新桌面中的阶段，不会提交招聘网站的申请。**

### 填写记录与简历快照

完成「一键 AI 填写」或「AI 辅助新增条目」后，可选择把本次填写留档。留档保存结果摘要和计数，例如字段数量、耗时和所用模板，不记录网页输入框中的实际填写值。

默认可附带本次使用的简历模板快照，也可以取消勾选。快照在填写开始时冻结，后续编辑模板不会改变它。它只能说明本次使用了哪份资料，不能证明网站最终收到了什么。

留档需要选择关联申请；没有候选时，可先保存岗位再「重新查找」，也可选择稍后在待同步中处理。取消留档不建立记录，也不暂存该次快照。

只有桌面确认持久化后才显示「已留档到桌面」。记入待同步时，会明确提示尚未留档到桌面。

### 待同步记录

侧边栏「填写」页的「待同步 N 条」支持选择留档对应申请、完成岗位保存、重试、删除记录和丢弃过期快照。关闭招聘网页后，队列仍可在侧边栏中查看。

请区分保存结果：

- 未安装或未配对：这次没有保存岗位，也不进入待同步；先安装并完成连接，再重新保存。
- 曾经配对、桌面暂时不可用或协议不兼容：允许记入待同步的操作会明确显示尚未保存到桌面，恢复连接后按提示处理。
- 没有回包（结果未知）：让你到桌面或待同步列表核对，不声称已保存、已排队或已确认。

简历字段和 AI 填写仍依赖桌面连接。快照暂存于扩展自己的 IndexedDB，传输完成后才清理副本。恢复桌面备份后，按界面提示核对队列，不要把恢复前的待同步内容误当成已写入新档案。

## 招聘材料与待办

「招聘通知」（原「证据收件箱」）支持导入 `.eml` 邮件、PNG/JPEG 截图、PDF，或通过「粘贴文本导入」保存一段文字；也可以把文件拖进窗口。文件被复制到本地档案中，移动或删除外部原文件不会影响已导入的副本。

左侧只列还没关联申请的材料。选中一条，在右侧阅读原文，点击“关联申请”选择具体申请并确认；通知类型与发送方式可在折叠的“手动设置通知分类”中修改。“AI 辅助整理”是独立的可选入口，打开入口不会自动发送分析请求。关联之后，材料会移到那条申请详情的「招聘通知」标签里；在那里取消关联，材料会回到待整理列表。

导入后由你确认关联和分类，不会因导入本身自动改变申请阶段。同一家公司多条申请需要自己选择，不会自动归并。AI 整理会先在弹窗中展示将发送给所配置服务商的内容和候选申请，由你确认后才发送；结果在审核弹窗中可以修改，点「确认」之前不会改动申请阶段或建立待办。「暂存」保存的是模型给出的建议，不保存你在审核中尚未确认的修改。

以下连接流程对应主分支开发能力，不能据此认定已包含在公开的 desktop-v0.4.4 中。QQ、163、126、Gmail、iCloud、新浪、搜狐、阿里个人邮箱和 139 邮箱已有 IMAP 配置入口，但各家真实账号尚未完整验收；学校或其他邮箱可尝试识别／手填，不承诺连通。已验证页面、账号、平台和未测项见 [邮箱支持矩阵](desktop-mvp/mailbox-acceptance.md)。Outlook 官方连接、Graph 自动收信和新增网页适配暂缓；这些邮箱及 Outlook `.msg` 或虚拟拖拽对象仍需另存为 `.eml` 或粘贴正文。单个文件上限 25 MiB，一次最多 20 个。邮件正文显示安全文本及原件中的内嵌照片，点击照片可放大；远程图片不会自动加载。独立 PDF 材料可用系统程序打开本地副本。

### 自动发现招聘邮件

1. 在「设置 → 邮箱」点击“添加邮箱”，或在「招聘通知 → 添加通知」选择“连接邮箱”。未添加邮箱时，设置页显示空状态；已有邮箱时优先显示账号列表。
2. 在弹窗填写完整邮箱地址，点击“下一步”或按回车识别。先查本地预设，未命中时尝试 DNS 查询（总预算 3 秒），不调用 AI；输入、停顿或离开输入框不会触发查询。
3. 常见邮箱直接进入密码步骤，按当前邮箱的教程准备授权码或应用专用密码。学校或机构邮箱识别不全时，先按官方说明核对收信服务器、端口、加密方式和登录用户名；跨域服务器须明确核对后，才能填写密码。网页登录地址不能作为收信服务器地址。
4. 点击“连接并添加”，测试通过并安全保存后弹窗关闭，留在邮箱列表。密码只存系统凭据库，不写入 SQLite、日志或备份，不回显。可添加多个邮箱；从账号行的“修改连接”或“更新密码或授权码”重新测试。修改收信设置前会说明候选与扫描记录的重置影响，已存档邮件保留。
5. 首次检查最近 30 天的来信，之后在应用运行时约每 10 分钟检查一次。添加完成后检查在后台进行；列表显示结果，需要时点击“查看待确认来信”。检查失败不代表添加失败，可重试检查；连接失败则保留表单供修改，关闭弹窗清除临时密码。
6. 在「招聘通知 → 待确认」查看标题、发件人、时间与入选原因。点击“存进档案”才下载整封原文；可批量确认或忽略。忽略不移动原邮件。入档后再由你选择申请、确认关联或使用 AI 辅助整理。

学校邮箱尽量支持，不承诺所有学校都能连接：学校可能没有开放 IMAP、要求校园网，或者毕业后回收邮箱。遇到问题按设置页提示核对；连续失败 3 次自动暂停，处理后点「恢复检查」。无法连接时，可取消填写，从网页版邮箱下载 `.eml`，到「招聘通知 → 添加通知 → 导入文件」保存，也可选择粘贴文本。筛选可能漏信，手动导入始终可用。

本机保存连接配置、候选和忽略状态，不自动上传分享，也不随档案备份迁移。更换机器需重新连接。断开邮箱会清除该账号的本机连接记录和凭据，已入档邮件保留。

软件完全退出后停止检查，关窗隐藏到托盘仍会检查。没有 Message-ID 且信头完全相同的异常邮件可能无法区分；筛中也不代表真实性已获验证。下载失败的候选保留，可恢复网络后重试。恢复 / 回滚档案不会回滚本机邮箱扫描记录。

「待办」左侧按时间分组列出任务，可按未完成、已完成、已取消或全部筛选；右侧显示选中待办的到期时间、时区、提醒时刻、面试轮次和提醒状态。新建待办需要关联一条申请（没有申请时先新增申请），建好后关联的申请不能更换；可设置无到期日、仅日期或具体时间。编辑时清空提醒时刻、时区或面试轮次会真正清除原值；改期会撤销原来登记的提醒并按新时间重新登记。完成、取消和重新打开直接生效，可随时撤回。系统提醒受权限、系统状态与平台能力影响，应用中会显示当前能力与运行条件。关闭窗口仍会驻留；主动退出会暂停提醒。重要测评和面试请保留其他提醒方式。

在「设置 → 数据与备份」导出备份或预览恢复内容。备份不包含 API Key；恢复前核对范围，按界面提示确认。更详细的数据范围见[数据与隐私说明](desktop-mvp/data-privacy.md)。

## AI 填写耗时与诊断

按钮会显示扫描、AI 匹配计时和填写阶段。「填写诊断」保留错误类别和失败阶段（扫描、匹配或填写）、是否判断为网申填写页、输入框漏斗（页面共有、可见可填、进入匹配、匹配、填入）和每一步丢掉的原因，以及扫描、匹配往返、API、填写与总耗时、AI 返回前先填了几项、提示词字节数，可复制反馈。没跑的阶段显示“未执行”，跑了但没拿到结果的显示“未取得”，AI 没被调用显示“未调用”，都不会显示成零耗时。在不是网申填写页的页面点一键填写，侧栏会提示先打开申请表页面，这种情况不自动上报。

一键填写时，姓名、邮箱、手机号这类本地就能确定的字段会先填上，不用等 AI；其余字段等 AI 返回后再补。AI 选的选项让网页清空了先填的字段（比如选了证件类型，证件号码被清空），会再填一次；先填时下拉框的选项还没加载出来的，AI 返回后也会再试一次。已经有内容的字段不会先填，AI 返回后和其他要覆盖的字段一起只问一次。等 AI 的这段时间里你自己改过的字段，AI 返回后不会被覆盖，填完时会列出来请你核对。

等待超过 30 秒会提示已经先填了几项。普通一键填写的日常模型请求，桌面最多等 120 秒；超时后会提示等了多少秒，并按卡住的地方说明是连不上服务商、服务商一直没响应，还是已经响应但结果没收完。可点击「取消 AI 等待（保留本地匹配）」主动终止等待，本地匹配到的照常填上，已经填上的保留，但这不能保证上游停止计算或计费。

AI 失败或主动取消后，会使用已验证的本地匹配结果，并明确提示部分完成；不会自动重试或更改接口设置。浏览器退出、扩展重载、网络或上游服务异常仍可能中断请求。

诊断摘要包含版本、计数、字节数、耗时和标准错误类别，另附网站域名（不含路径和参数）、页面结构线索（内嵌框架、自定义控件、「编辑」按钮等的数量），以及没填上字段的字段名和控件结构（标签、类型、组件库）。字段名最多保留 16 个字；含 @、网址、长串数字，与要填写的值重叠，或包含简历里的内容时隐藏。诊断不包含字段值、接口地址、API Key、简历正文或上游错误原文，只在本机显示；点「复制诊断」后由你决定发给谁。截图前仍需检查周围网页和模板中的个人信息。

## AI 辅助新增条目

这是可选实验功能，不改变普通「一键 AI 填写」的使用方式。

网页只显示一条论文或经历时，可点击「AI 辅助新增条目」。插件先识别候选新增按钮，交给 AI 规划；侧边栏展示计划后，由你点「确认新增」，再逐次新增并填写新分组中的空文本字段。

规划阶段只发送候选新增按钮的编号、类型和条目数量，不发送简历正文。后续匹配新字段时，会使用相关简历内容。通常需要规划与匹配两次模型调用。

支持明确标注的论文、教育经历或教育背景、工作经历、项目经历。需要结构清晰的分组和唯一新增按钮，每次最多新增 5 条；结构不明确时请手动操作。没有正式工作经历时，可用实习经历推导通用工作分组的条目数；两类同时存在时不会自动混合。

此辅助模式只填相关分组的空文本框和文本域，复杂下拉框、日期等控件不纳入该模式。写入后会短暂等待并读回确认，但这不能证明网站服务器已保存。

预览期间切换标签页、网页地址或模板变化、分组变化，会使计划失效，需要重新预览。执行中遇到按钮变化、数量异常、网页重建字段，或 2.5 秒内未确认新增，会停止且不重复点击。

可在规划和新增期间停止。停止或失败时，已经新增的空条目不会自动删除，界面会显示实际新增数量；网站自身的新增操作可能触发保存，确认前请留意。

## 深度分析本页

普通「一键 AI 填写」靠固定规则找输入框，有些网站的字段扫不到、对不上或写不进去。这时可以在侧栏点「深度分析本页」：插件先把页面结构整理成一份大纲，交给桌面设置的强模型（没设强模型时用当前服务商）看懂哪些是字段、字段名是什么、属于哪个分组、是哪种控件，再按这份说明重新匹配并填写。

- **什么时候用**：一键填写后扫描到 0 个字段、有字段没填上或未确认，或者页面上有插件没认出来的下拉框等控件时，填写结果下面会突出提示。其他时候「深度分析本页」作为次要入口放在「AI 辅助新增条目」下方，觉得填得不对也可以主动使用。连不上桌面、没配置 AI、Key 无效或网络失败时不会提示，因为深度分析同样会失败。
- **第一次使用**会先说明要发送什么，点「同意并开始分析」后才发送，以后不再询问。
- **发送什么**：分析只发送页面结构大纲，包括控件类型、字段名、分组标题、按钮文字和提示文字。输入框里已有的内容不读取、不发送；密码框、验证码等整体跳过；手机号、邮箱、证件号、网址、像密钥的文字，以及和你简历内容相同的文字，发送前都换成「〔内容〕」。每段文字最多 40 个字。之后的填写匹配和「一键 AI 填写」一样，会把相关的简历字段发给 AI。
- **花多久、花多少**：分析通常需要 10～60 秒，可以随时点「停止」。一次深度分析（分析、动作之后的再分析和填写匹配合在一起）最多调用 6 次模型，用完就停止并说明。页面特别长时只分析前面的部分，侧栏会提示。
- **先点「编辑」「展开」「添加」**：AI 判断要先点这些按钮时，侧栏会列出要点的每一项，例如「基本信息：编辑」「教育经历：添加 ×1」；鼠标移到某一项上，网页上对应的按钮会被框出来。你点「确认执行」之后插件才点击，「取消」则什么都不点。
  - 一项一项地点，一次最多 5 个「编辑 / 展开」。每点一下都等网页安静下来（最多 5 秒），并核对确实出现了新的输入框；没出现、网页一直在变、已有内容被改掉、按钮被换掉、网址变了或页面要离开时立即停下，后面的都不再点，也不会继续填写。可以随时点「停止」。
  - 「添加」只用于教育、工作（含实习）、项目、论文这几类经历：新增几条由插件按桌面模板里的记录数和网页上已有的条目算，不由 AI 决定；每次合计最多新增 5 条，超过时一条都不加，侧栏会说明，请先手动新增一部分。网页上已有条目数不清、同类分组不止一个时同样不新增并说明原因。每次只点一下、确认只多出一条；已经新增的空条目不会被自动删除。
  - 同一次分析里既要「编辑」又要「添加」时，先只做编辑；编辑完填写后，如果条目还不够，再点一次「深度分析本页」来新增。
  - 动作做完后，插件重新生成页面大纲、再分析一次，然后照常填写。这一轮 AI 如果还提出要点什么，只会提示，不会再点。
  - 永远不点「提交」「保存」「确认」「删除」「下一步」「投递」「返回」「取消」这类按钮，不点会打开新页面或别的网站的链接，也不会自动保存或提交。「编辑」会打开新页面的，侧栏请你手动点，在新页面上再分析。
- **安全规则不变**：覆盖已有内容前照样询问；填写期间你改动过的字段不会被覆盖；敏感字段过滤、本人和家属信息分开、选项必须是网页原文这些规则都照旧。AI 给出的页面说明如果引用了大纲里不存在的元素、类型不合法或指向「提交」「删除」这类按钮，整份作废，网页不做任何改动。
- **暂不支持**：跨域内嵌框架里的表单、富文本编辑框。

深度填写的「填写诊断」会多三行：大纲字数和分析次数、页面说明书的字段数和校验结果、这次一共调用了几次模型以及实际用的是强模型还是日常模型。执行过「编辑 / 展开 / 添加」时再多两行：计划和完成的动作数量、停止原因、分析了几轮。不包含网页文字、按钮文字、模型回复原文或填写的值。

### 本站配方

深度分析确实有用时，插件把这次的页面结构记成「本站配方」，下次在同类页面「一键 AI 填写」时先按配方找字段，不再做页面分析。

- **什么时候保存**：深度分析的说明通过校验、你没有取消或停止，并且核验后填上的字段比同一页面上一次普通「一键 AI 填写」多（普通填写一个字段都扫不到的页面按 0 算）。没有先在这个页面普通填写过、没有填上任何字段、效果没有更好时都不保存，深度分析卡片会说明原因。保存成功后侧栏填写区出现「本站配方：已保存」。
- **哪些页面算同一类**：同一个网站域名，路径一样（路径里 3 位以上的纯数字、UUID、很长的十六进制编号视为同一个位置，查询参数和 # 后面的部分不看）。不同域名不会共用；同一网站的不同页面可以各有一条。路径里可能带个人信息（邮箱、手机号、和简历相同的文字、像令牌的长串）时不保存。
- **怎么用**：网址只用来找配方，能不能用要看网页上的字段：配方里至少 80% 的字段都能唯一找到、找不到的不超过 5 个才按配方填；同名控件、得分相同说不清是哪个、控件不在了的都不猜。插件的普通扫描同时补上配方里没有的字段，同一个控件只填一次。
- **过期了**：网页改版、找到的太少时不按配方填，照常扫描填写，结果里提示「本站配方可能已过期，可以重新深度分析」，侧栏显示「可能已过期」。插件不会因此自动去做深度分析，要不要重新分析由你决定。
- **要先点按钮的页面**：配方里有「编辑 / 展开 / 添加」时，一键填写会先在侧栏列出要点的按钮，每次都要你重新确认，不会因为上次确认过就直接点；「添加」几条按当前模板和网页上已有的条目重新算。点完再按配方找字段（不拿点之前还没出现的字段凑数），停止、取消、按钮对不上或页面变化时立即停下。网页已经是编辑状态、配方字段全都在时不点。同一次既要编辑又要添加时，和深度分析一样先只编辑。
- **分组没记住、找不到时会说明**：保存时某个经历分组的已有条目数不清，插件不会记住它的「添加」，卡片上会写明是哪一组；下次某一组的「添加」按钮在网页上找不到（例如这个职位的表单没有论文），这一组这次不新增，侧栏同样会写明。
- **花费**：按配方填写不做页面分析，不调用强模型；匹配简历仍和普通一键填写一样用日常模型，所以并不是完全不调用模型。诊断里会写「本站配方：命中 / 过期 / 新保存 / 未保存 / 未使用」、定位到几个字段和这次调用了几次模型。
- **重新分析、删除**：「本站配方」一行的「重新分析」就是深度分析本页（同样的首次说明、停止和调用上限），效果更好时更新配方；「删除」只删当前页面这一条。
- **存在哪里**：只存在这个浏览器的扩展本机存储里，不上传、不同步到桌面或别的浏览器、不进桌面备份，也不随留档或反馈发送。配方只记结构（字段的题目和分组文字、控件类型、稳定的属性、按钮文字），不记填写值、简历内容、网页正文或完整网址。最多 200 个网站，单条不超过 32 KB，超出时删除最久没用的。

## 旧版数据迁移

0.4.0 及更早的扩展将模板、「我的信息」和 AI 配置保存在浏览器中。升级到 0.4.1 的桌面协作方式时：

1. 安装桌面应用并连接浏览器。
2. 扩展发送旧数据，在桌面「简历」页核对待导入内容。
3. 点击「导入到桌面」。桌面已有「我的信息」时，自行选择保留哪份。
4. 导入成功后，扩展清理已经完成迁移的旧数据。

**确认之前不会删除旧数据。** 选择「不导入」后，仍可在插件状态页重新发送。不要在迁移或取回完成前卸载旧扩展、删除浏览器 Profile 或清除存储。

密码、验证码类的「我的信息」字段不会迁移。超过 24 KB 或超出 25 套数量上限的模板不会迁移，可在插件状态页下载 CSV，再到桌面导入。

若系统凭据库暂时不可用等原因导致 AI 配置导入失败，简历仍可迁移，未迁移的旧 API Key 会留在扩展。可在插件状态页取回，到桌面配置后再删除旧副本。

## 常见问题

### 点击图标没有打开侧边栏

确认扩展已启用，浏览器为支持的版本，并刷新已打开的网页。`chrome://extensions`、`chrome://settings`、`edge://extensions` 等浏览器内部页面不能注入普通扩展内容，请在普通招聘网页测试。侧边栏左右位置由浏览器设置决定。

### 连不上桌面或提示没配置 AI

确认桌面已安装且能启动；按侧边栏的未配对、缺少桌面或版本提示处理。商店版本尚未同步时，可使用发布页配套 ZIP。连接正常后，在桌面「设置 → AI 设置」确认服务商已设为「当前使用」，地址、模型和 Key 已填写。

### AI 接口请求失败

检查 Key 是否失效、余额和限流、模型名称与权限、接口地址，以及接口是否兼容 OpenAI Chat Completions。侧边栏诊断会区分认证、限流、超时、网络等问题。

慢响应可能来自模型、转发服务、网络或输入量，不能仅凭等待时间断定某一方故障。不要在反馈中公开 Key 或未脱敏的请求正文。

### Excel 导入失败

确认文件为 `.xlsx` 或 UTF-8 `.csv`，第一行为表头，前三列依次为「一级分类 / 字段名 / 值」，每行第二列都有字段名。按提示行号修正后重新导入。

### 提示“没找到可填写的输入框”

不在申请表页面时，请先打开申请表再试。在申请表页面上点得太早时，插件会等表单出来，最多等 2 秒，出来了就接着填。仍然没找到，多半是网页还没加载完，或者要先点开某一块才会出现输入框：等网页加载完，或先点开要填写的部分，再试一次。

猎聘等网站的在线简历默认是查看状态，要先点网页上的「编辑」，等输入框出现后再一键填写。这类网站通常每块单独编辑、单独保存，需要一块一块填。插件检测到「编辑」按钮时会直接这样提示；页面处在查看状态时，「已填写 0 个字段」或「简历里没有能对应这些网页字段的资料」后面也可能跟着同样的「先点编辑」提示。页面明明有输入框却扫不到时，可以试试「深度分析本页」；它也可以在你确认后替你点「编辑」，再分析和填写。表单在跨域内嵌框架里或用了暂不支持的控件时，请按下一节的方式反馈。

### 字段填错或网站显示仍未填写

手动核对并按网站要求完成交互，尤其留意日期、学历、证件类型、地区、级联下拉框与多段经历。网页控件显示有文字不保证网站已经接受或保存该值。

兼容性反馈请提供网站域名、卡在哪一步、打码后的截图，以及展开侧栏「填写诊断」、点「复制诊断」得到的文字。可复现问题用 [GitHub Issues](https://github.com/TshyGO/resume-form-assistant-plugin/issues/new/choose) 的「网站填不上 / 填错」模板提交，也可以先到[QQ 交流群](../README.md#-qq-交流群)交流。


## 手动坚果云备份与恢复

1. 在坚果云账户中创建第三方应用密码。打开桌面「设置 → 数据与备份 → 备份到坚果云」，卡片顶部先显示配置状态、最近成功和自动备份情况；展开「坚果云账号与加密」，在同一处填写账号、应用密码、远端目录和备份加密口令，一次保存即可备份。默认地址为 `https://dav.jianguoyun.com/dav/`，改过地址可点旁边的「使用坚果云地址」恢复。自定义服务必须使用 HTTPS。目录可以留空或填写斜线分隔的子目录；目录不存在时，第一次备份会自动创建。
2. 保持「上传前加密」勾选并设置备份加密口令，另行保管。缺应用密码或勾选加密却没设口令时，保存会在对应输入框提示。留空不会覆盖已保存的秘密，保存后不回显；输入框旁显示「已保存」并可点「移除」。换账号或地址须重新保存对应凭据；移除凭据不会删除已有云端备份。丢失加密口令无法恢复。
3. 点击「测试连接」确认账号可读取目录；这一步不上传档案、不创建目录，也不保证上传权限。目录尚不存在时，会再只读检查一次 WebDAV 根目录：能读到才提示账号验证通过、首次备份时创建；地址或账号有误则直接报对应错误。点击卡片右上角「立即备份」后可看到生成、加密、上传、确认阶段，可以取消。密钥计算不可即时中断，取消会在安全边界生效。网络失败时用「重试上次备份」对账并沿用原候选包；明确放弃后才能新建，未确认远端残留可用服务商文件管理器人工核对。
4. 卡片顶部显示最近成功时间（鼠标悬停可看 UTC）和大小；本机明文副本路径在「坚果云账号与加密 → 了解更多」。即使云端加密，本机仍有明文副本，请保护用户数据目录。「坚果云账号与加密」里的「保留份数」默认最近 5 份：每次备份成功后，删除这台电脑上传的更早备份，每次最多 10 份，积累较多时会在之后几次备份中逐步删完。只删本机记录过的备份；其他设备的备份、你自己放进目录的文件都不会动。服务商列表偶尔漏项时会多留几份，不会多删。选「全部保留」则从不自动删除。
5. 新机器只需填写同一账号、地址、根目录与备份口令并保存。点击「查找云端备份」，按档案及来源设备选择，不需要记住旧设备 ID。列表只读取云端目录，通常几秒内先显示最新 10 份；点「再显示 10 份」继续查看更早的备份，需要时才读取更早的月份，可以取消。查找结果可用右上角「收起」关闭。列表**不是内容校验的证明**，点「下载校验并预览」时才核对元数据和内容，解密前不展示业务数量。
6. 选择「下载校验并预览」，等待传输哈希、解密认证与内部文件校验；进度、包大小和「取消」显示在被点的那一行，失败原因也显示在该行。核对数量对比后点击「确认替换当前档案」。预览有效十分钟；过期或文件改变必须重新下载预览。取消、失败不替换当前档案，并会尝试清理临时明文；若界面提示「临时明文清理未确认」，请按提示重启应用后检查工作目录。
7. 恢复是整个档案替换，不是合并；原档案保留在「回滚点」，可随时换回。恢复后插件旧队列会因 epoch 改变而暂停，请按提示重新连接核对。本机自动云备份关闭；先按当前配置完成手动备份，再重新确认自动计划。

常见错误：认证失败时检查第三方应用密码；权限不足时检查远端目录授权；限流时等待后再试；空间不足时清理对应本机/云端空间；损坏或口令不符时检查口令或改选其他备份。不要反复点击创建新包来处理上传结果不明确的错误。

云备份直接发给你配置的存储服务商，不经过项目服务器，也不是实时同步。本地「导出备份」仍生成未加密 ZIP。详见 [隐私政策](privacy-policy.md#可选手动云备份与恢复)。


### 可选自动云备份

默认关闭。先用当前账号、目录和加密设置完成一次手动云备份，再展开「自动备份」，选择时间、频率、固定时区和本机预算，核对估算后点击「确认并启用」。启用后折叠栏右侧显示当前计划，可用「关闭计划」停用。默认超出预算暂停，也可以明确选择仅提醒。

- 仅在程序运行时每约 30 秒检查，隐藏到托盘仍会检查，退出后不运行；不会创建系统计划任务。每天/每 3 天/每周按固定 UTC 偏移计算日期，首次执行取下一个所选时间，之后按频率递增。时区明确显示，旅行或夏令时不自动改计划；需要跟随新时区时重新选择并启用。
- 程序关闭、休眠或长时间挂起错过时间后，只显示补备份提示，不自动抢跑。需要时用「立即备份」。系统时钟回退会暂停计划，重新确认后恢复。实际执行可能晚约 30 秒；超过 2 分钟或检查中断超过 2 分钟视为错过。
- 内容相同跳过加密和上传。申请、事件、待办、证据、简历模板/状态、已完成快照、文件引用及删除会影响判断；只改打包时间不会触发上传。附件内容异常则报错，不能当作未变化跳过。
- 估算为最近成功包大小 × 每 30 天最多执行次数；没有包时显示不可用，包体增长和重试会增加用量。本机预算按第一次上传尝试开始的连续 30 天周期估算，与坚果云账户重置日不同。每次实际上传前预记整个包体/元数据大小，即使响应丢失也不返还，因此可能高估；对账下载、协议开销、能力探测和其他设备/应用不在此数字内。绝不显示账户「剩余流量」。
- 本机达到估算预算的 80% 提醒，超过所设预算时默认暂停自动上传；手动操作不受此暂停限制。坚果云免费账户的官方参考为每月上传 1 GB、下载 3 GB，重置不一定是自然月，以[官方规则](https://help.jianguoyun.com/?p=29)和账户页面实际显示为准。
- 网络、限流、服务端暂时错误最多自动重试 3 次，基本间隔 60/120/240 秒，并等待更长的 Retry-After；重试复用同一候选包，结果不明先对账。认证、权限、空间、大小、预算等错误暂停，请按错误提示处理后手动重试/放弃，再重新启用计划。已成功上传但清理失败只提醒，不重新上传。
- 恢复、回滚或编辑云配置会关闭自动计划；中断或取消的任务不会在重启时自动重试。设置页及全局提示显示错过/暂停；设置页还显示下次计划、跳过原因、重试等待、最近成功与明文位置。退出时尽力取消，异常退出后的未完成任务标记中断，保留候选供手动处理。

真实服务商及 Windows/macOS 人工验收继续由 #306 跟踪。自动检查不代表已验证真实坚果云或全部系统睡眠行为。


更换或移除已保存凭据会关闭自动计划。**更换/移除加密口令会使自动基线失效**；正在处理的旧候选即使之后上传成功，也不能重新建立新口令的基线。完成一份新的手动备份后才能再次启用自动计划。已有云端包和待重试候选不会被重新加密，恢复它们仍需创建时的口令，请分别保管旧口令。


### 从网页邮箱保存一封招聘邮件

本节描述主分支的 QQ、163／126 网页适配，不能外推所有页面或视为公开插件 v0.4.4 已提供。QQ 只有部分历史真实验证，网易真实下载仍待补测；Gmail 网页保存仍在 [PR #419](https://github.com/ptjworks/resume-form-assistant-plugin/pull/419)，未合入／发布，不能按本节当作已交付支持。详细状态见 [邮箱支持矩阵](desktop-mvp/mailbox-acceptance.md)。

在 QQ、163 / 126 网页邮箱打开邮件，打开网申快填侧栏，切换到第三个「邮件」栏目。「关联申请」始终展开，输入公司名称后按回车或点击「查找申请」；结果直接显示在搜索框下方，岗位在前、“暂不关联”在最后。点击岗位整行选中，下方明确显示公司与岗位，再点「保存并关联」。默认预选“暂不关联”，可直接点「暂不关联并保存」，保存到桌面「招聘通知」。修改公司名称会清除旧选择，需要重新查找。不需要简历模板或 AI 配置。

侧栏固定为「填写 / 简历字段 / 邮件」，默认选中填写；打开邮箱不会自动切走。栏目间切换保留关联选择和待确认的摘录。普通网页的邮件栏目会显示支持的邮箱，保存按钮不可用。桌面端需升级到支持存邮件的版本。

优先保存完整邮件原件（包括原件内嵌附件）。取不到原文时会提示缺少原件和附件，你可以点击「保存网页摘录」或取消。摘录只保存页面上的发件人、标题、发送时间和正文，可能无法与之后导入的原件自动去重。成功后到桌面「招聘通知」查看；连接失败时请重试，未显示成功不代表已经归档。邮箱页面改版可能需要更新适配，暂不支持的页面可以下载 `.eml` 后在桌面导入。


### 查看邮件中的附件

在桌面“招聘通知”选择邮件，正文上方会列出附件；已关联的邮件也可在“申请 → 对应申请 → 招聘通知”里查看。点击文件名打开附件窗口，左侧切换文件，右侧查看内容。正文内嵌照片会在文字之间显示，点击可放大；单独上传的同一张照片仍保留在附件列表。

- PDF 可翻页、放大、缩小或适合宽度；图片也可缩放。PDF 和图片内预览上限为 8 MiB，超限时可以另存为或用系统程序打开完整文件。
- XLSX 可只读查看单元格，并切换工作表；预览显示前 500 行、50 列，达到上限会提示。完整排版、图表及公式计算请用系统程序打开。
- 内容与扩展名匹配的 PDF、PNG / JPEG / GIF / WebP 图片和 XLSX 可点“用系统程序打开”；Word、旧版 `.xls`、压缩包、HTML / SVG 和其他类型仅提供“另存为”。
- “另存为”取消后不会保存文件；关闭附件窗口回到原通知。已有邮件无需重新导入。
- 预览从本机保存的邮件读取，不访问邮箱、不调用 AI。系统打开使用临时副本，对副本的修改不改变档案里的原件。同一附件重复打开会复用未改动副本；外部修改过的副本再次打开时会从原件重新生成。临时副本最多 16 份、合计 64 MiB；达到上限时可另存为，或稍后重试。下次打开时尝试清理一小时未打开的副本，桌面完全退出时清理，启动时重试清理旧副本；外部软件占用时可能需要先关闭文件。网页摘录未保留邮件原件和附件，因此不提供附件列表。
