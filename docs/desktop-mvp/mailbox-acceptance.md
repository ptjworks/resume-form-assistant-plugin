## 2. 邮箱与入口矩阵

“原件”指完整 MIME，包含邮件内嵌附件；不包含附件中的网盘链接。“摘录”只保留页面可读文字，明确缺少原件与附件，不能保证与后来原件自动合并。网页保存仅由用户显式点击触发；IMAP 先发现信头，用户确认后才下载整封。

所有行均可尝试标准 `.eml` 通用文件导入；这是格式能力，不等于该服务商的连接或网页适配通过。QQ、Gmail 已有的网页／手动入口证据见 E01／E02，Gmail IMAP→手动入口见 E04；其余品牌及平台未由这些证据外推。
