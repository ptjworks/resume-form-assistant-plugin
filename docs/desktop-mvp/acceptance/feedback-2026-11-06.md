## 首轮审查处理

重绑时读取文档、查询锚点均保持在异常边界内；支持 CSS.escape 的浏览器用精确 id 选择器查询并检查重复，否则按 id 属性遍历判定。单选组 radio 仍用原组级重复项定位，不以某一个选项的 id 放宽整组身份。焦点回退的文档、视图和事件构造不可用时由后续提交核验决定结果，避免直接中断整页。

保留以下行为：通用提示仍由 cleanLabel 的通用噪声规则过滤；前台已聚焦的输入框不凭空制造新焦点转换；选中值的隐藏判断不看视口位置或 opacity，多选在 selectedTexts 的前置独立分支处理。Element 自动完成不按 el-select 识别，仍沿用联想输入路径。这些未按自动建议扩大匹配或改变既有多选规则。
