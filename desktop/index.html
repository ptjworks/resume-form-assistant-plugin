        手动安装（商店暂时无法安装时）

        1. 步骤 1下载并解压

          点「下载插件包」，把下载的压缩包解压成一个文件夹。

        2. 步骤 2打开扩展管理页

          在地址栏输入 chrome://extensions；Edge 输入 edge://extensions。

        3. 步骤 3开启开发者模式

          Chrome 在页面右上角，Edge 在左侧栏底部。

        4. 步骤 4加载已解压的扩展

          点「加载已解压的扩展程序」（Edge 为「加载解压缩的扩展」），选中解压出的文件夹。
